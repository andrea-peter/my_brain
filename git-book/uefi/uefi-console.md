Enter a filesystem: `FS5:`

`ls`: List files

`cat`: List file content

`cd`: Enter directory

`edit <filename>`: Edit a file

* `CTRL`-`E`: Editor help

{% hint style="warning" %}
UEFI cannot write on `etx4`, only FAT
{% endhint %}
